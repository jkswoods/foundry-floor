# Building progression {#building-progression}

Foundry Floor is an architectural collection with a small mechanical layer. There is no research, machine processing, power network or higher-tier material chain.

## Start on the ground {#start-on-the-ground}

Follow the base game's material progression to Iron and Copper Ingots. The configured starting cost is **8 iron + 4 copper** for the Foundry Workbench. Extra iron buys floor blocks in batches. Foundry crafting was included in player testing.

A useful first project is an eight-plate loading bay. Add a connected safety edge where goods enter and concrete around larger equipment.

## Add a service level {#add-a-service-level}

Use stairs, rail-sided catwalks and corners to create a maintenance walkway. Independent railings protect landings. Stack columns and crossbeams to frame the upper level. Match the stair's one-block rise with its landing height.

## Finish the building {#finish-the-building}

Add a loading-bay shutter, personnel door, service hatch and guarded lights. Ducts, vents and pallets fill out the interior without creating new resource systems.

Elevators are deferred to a future release. Use stairs and catwalks for vertical factory access.
